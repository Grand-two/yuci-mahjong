🎯 基本规则概述

榆次麻将流行于山西晋中地区，是具有地域特色的四人麻将游戏。

⚠️ 核心规则

报听才能胡牌！
要胡牌必须先报听（叫做"上架"），听牌后系统自动抓牌、出牌、胡牌。
必须缺一门！
胡牌时手上不能有三种花色的牌，只能保留两种花色。
可碰、可杠、不可吃
与其他麻将不同，榆次麻将不能吃牌，只能碰牌或杠牌。

👥 玩家人数

4人对战，每人13张手牌，庄家14张。

🎮 基本流程

  1. 庄家掷骰子，确定摸牌位置
  2. 庄家起手14张牌，其他玩家13张
  3. 由庄家开始，轮流摸牌出牌
  4. 可碰牌、可杠牌，但不可吃牌
  5. 报听后才能胡牌

🏆 胡牌类型

榆次麻将胡牌需要满足 4组面子 + 1对将，且必须报听 + 缺一门。

📋 基本牌型说明

  • 面子（mianzi）： 3张牌组成
    • 顺子：同花色连续3张（如 1-2-3万）
    • 刻子：相同3张（如 3个5饼）
    • 杠子：相同4张（如 4个8条）
  • 将牌（jiangpai）： 2张相同的牌（如 2个红中）

🃏 特殊牌型

一条龙 同花色123-789 10番
清一色 一种花色的序数牌 10番
字一色（风一色） 全是字牌组成 20番
龙套龙 清一色的一条龙 20番
七对 7个对子 7番
碰碰胡 4副刻子/杠 + 对子 5番

📌 普通番型

坎张 胡2张牌之间的牌 1番
边张 胡123的3或789的7 1番
单钓 单吊一张牌胡牌 1番
门前清 未碰未杠，自摸胡牌 1番
断幺 胡牌中无一、九及字牌 1番
报听规则：
摸到听口的牌后，必须打出一张并扣倒（不让人看到），同时声明自己听牌了。报听后不能碰、杠，只能等胡牌。

📊 计分规则

榆次麻将采用基本番 + 奖励番的计分方式。平胡2番起算。

⚖️ 杠牌规则

  • 明杠（别人打出的牌杠）：被抢胡无加番
  • 暗杠（自己摸到的牌杠）：不算番
  • 杠随胡走：赢家有杠加番，输家有杠无加番
  • 抢杠：抢杠者无加番，包牌

💰 点炮规则

  • 已报听：各付各的（点炮者付胡牌者）
  • 未报听：包三家（点炮者付三家）

🎲 掷骰子确定摸牌位置

榆次麻将用两颗骰子、两次掷骰确定摸牌位置，核心是"先定方向、再定墩位"。

📖 两次掷骰规则

第一次掷骰（庄家掷）→ 确定第二次掷骰人
点数和第二次掷骰人
5、9点庄家（自己）
2、6、10点下家（右手边）
3、7、11点对家
4、8、12点上家（左手边）
口诀：五九自手，二六十过，三七对门，四八到底
第二次掷骰 → 确定留墩数

由上一步确定的人再掷两颗骰子，两次点数相加得到总点数。

在第二次掷骰人的牌墙上，从右往左数，跳过总点数对应的墩数，从下一墩开始摸牌。

🔄 轮庄方向：庄 → 上家 → 对家 → 下家（逆时针）
🎯 出牌方向：庄 → 下家 → 对家 → 上家 → 庄（顺时针）

📋 抓牌与出牌顺序

  • 抓牌顺序（逆时针）：庄 → 上家 → 对家 → 下家
  • 出牌顺序（顺时针）：庄 → 下家 → 对家 → 上家 → 庄
  • 庄家先抓4张，每人抓3轮（每轮2墩=4张），共12张
  • 庄家再抓2张（共14张），其他人各抓1张（共13张）
